# Dev-UI2 分支创建脚本使用说明

## 📋 概述

本目录包含了用于创建 `dev-ui2` 分支并提交UI优化修改的自动化脚本。

## 🚀 脚本文件

### 1. `create-dev-ui2.bat` (Windows批处理脚本)
- **用途**: Windows环境下创建dev-ui2分支
- **使用方法**: 双击运行或在命令行中执行
- **特点**: 支持彩色输出，详细的错误处理

### 2. `create-dev-ui2.ps1` (PowerShell脚本)
- **用途**: PowerShell环境下创建dev-ui2分支
- **使用方法**: `.\scripts\create-dev-ui2.ps1`
- **特点**: 更现代的脚本语言，更好的错误处理

## 📝 脚本功能

### 自动检查
- ✅ 检查Git是否已初始化
- ✅ 检查当前分支状态
- ✅ 检查是否有未提交的修改

### 自动提交
- 📝 自动添加所有修改的文件
- 📝 生成详细的提交信息
- 📝 包含所有UI优化的详细描述

### 分支管理
- 🌿 创建新的 `dev-ui2` 分支
- 🔄 自动切换到新分支
- 📊 显示分支状态和提交历史

## 🔧 使用方法

### Windows批处理脚本
```bash
# 方法1: 双击运行
双击 create-dev-ui2.bat

# 方法2: 命令行运行
.\scripts\create-dev-ui2.bat
```

### PowerShell脚本
```powershell
# 在PowerShell中运行
.\scripts\create-dev-ui2.ps1
```

## 📋 执行流程

1. **检查Git状态** - 验证Git是否初始化
2. **检查修改** - 检测是否有未提交的修改
3. **添加文件** - 自动添加所有修改的文件
4. **生成提交信息** - 创建详细的提交描述
5. **提交修改** - 提交到当前分支
6. **创建分支** - 创建并切换到dev-ui2分支
7. **显示状态** - 显示分支状态和提交历史

## 🎉 完成后的操作

脚本执行完成后，建议进行以下操作：

1. **推送分支到远程**
   ```bash
   git push -u origin dev-ui2
   ```

2. **创建Pull Request**
   - 在GitHub/GitLab上创建Pull Request
   - 将dev-ui2分支合并到主分支

3. **代码审查**
   - 进行代码审查
   - 确保所有修改符合要求

4. **合并完成**
   - 合并成功后删除临时分支
   ```bash
   git branch -d dev-ui2
   ```

## ⚠️ 注意事项

- 确保在运行脚本前已保存所有修改
- 脚本会自动处理所有未提交的修改
- 如果dev-ui2分支已存在，脚本会自动切换到该分支
- 建议在运行脚本前备份重要文件

## 🐛 故障排除

### 常见问题

1. **Git未初始化**
   - 解决方案: 先运行 `git init`

2. **权限问题**
   - 解决方案: 以管理员身份运行脚本

3. **分支已存在**
   - 脚本会自动处理，无需手动操作

4. **提交失败**
   - 检查是否有语法错误
   - 确保所有文件都已保存

## 📞 技术支持

如果遇到问题，请检查：
1. Git是否正确安装
2. 是否有足够的权限
3. 网络连接是否正常
4. 文件是否被其他程序占用
