### 测试1：验证Profile自动创建 ⏳

**执行时间**：5分钟

**步骤**：
1. 在Supabase Dashboard → Table Editor → profiles
2. 检查是否有对应新用户的profile记录
3. 或者执行SQL验证：

```sql
SELECT 
  u.email,
  p.username,
  p.preferences,
  p.created_at as profile_created_at
FROM auth.users u
LEFT JOIN public.profiles p ON u.id = p.id
ORDER BY u.created_at DESC
LIMIT 3;
```

**预期结果**：
- [ ] 每个用户都有对应的profile记录
- [ ] profile的`created_at`与用户的`created_at`非常接近（自动创建）
- [ ] `preferences`包含默认值

**如果profile未创建**：
- [ ] 检查触发器状态
- [ ] 可能需要手动创建或修复触发器
