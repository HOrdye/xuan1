### 4. Profile自动创建验证

#### 在Supabase SQL Editor中执行：

```sql
-- 查看最新注册的用户和对应的profile
SELECT 
  u.id,
  u.email,
  u.created_at as user_created_at,
  p.username,
  p.preferences,
  p.created_at as profile_created_at,
  EXTRACT(EPOCH FROM (p.created_at - u.created_at)) as time_diff_seconds
FROM auth.users u
LEFT JOIN public.profiles p ON u.id = p.id
ORDER BY u.created_at DESC
LIMIT 5;
```

#### 验证：
- [ ] 每个用户都有对应的profile记录
- [ ] `time_diff_seconds` 应该很小（< 5秒），说明是自动创建的
- [ ] `preferences` 包含默认值

## 🐛 常见问题

### 问题1：注册后profile未自动创建

**解决方法**：
1. 检查触发器是否正确创建
2. 在Supabase Dashboard中检查触发器状态
3. 手动执行触发器测试

### 问题2：登录后立即退出

**可能原因**：
- Supabase会话配置问题
- 前端代码问题
- RLS策略阻止访问

**解决方法**：
1. 检查控制台错误信息
2. 验证Supabase客户端初始化
3. 检查RLS策略配置
