# 紫微斗数动画效果说明

## 📋 概述

本文档说明紫微斗数模块的所有动画效果，包括星盘生成、视图切换、交互反馈等。

---

## 🎬 动画效果列表

### 1. 星盘生成动画 (`ZiweiChart.vue`)

#### 中心区域淡入
- **效果**：中心信息区域从缩放0.8淡入到1.0
- **时长**：800ms
- **缓动**：easeOutElastic
- **触发时机**：组件挂载时

#### 宫位依次出现
- **效果**：12个宫位从命宫开始，顺时针依次出现
- **动画**：透明度0→1，缩放0.5→1，位移20px→0
- **延迟**：命宫300ms，后续每个宫位延迟80ms
- **时长**：600ms
- **缓动**：easeOutBack

#### 星曜旋转出现
- **效果**：星曜从旋转180度、缩放0的状态出现
- **延迟**：基于星曜在宫位中的位置（主星优先，辅星其次）
- **时长**：400ms
- **缓动**：easeOutElastic

#### 四化标记动画
- **效果**：四化标记缩放出现
- **延迟**：1800ms后开始，每个标记延迟100ms
- **时长**：400ms
- **缓动**：easeOutBack

#### 格局卡片动画
- **效果**：格局卡片从下方滑入
- **延迟**：1000ms后开始，每个卡片延迟150ms
- **时长**：500ms
- **缓动**：easeOutQuad

## 🎨 动画技术实现

### 使用的库
- **animejs**：用于复杂的JavaScript动画
- **CSS Transitions**：用于简单的过渡效果
- **CSS Animations**：用于持续动画效果

### 动画原则
1. **性能优先**：使用CSS动画和transform，避免layout重排
2. **用户体验**：动画时长适中，不会让用户等待过久
3. **视觉反馈**：悬停和交互都有明确的视觉反馈
4. **层次感**：通过延迟和缓动函数创建层次感

## 🔧 自定义动画

### 调整动画速度

```typescript
// 在 ZiweiChart.vue 中
const animateChartGeneration = () => {
  anime({
    // ... 其他配置
    duration: 600, // 调整这个值来改变速度
  });
};
```

### 调整动画延迟

```typescript
// 宫位出现延迟
delay: (el: any, i: number) => {
  if (i === 0) return 300;  // 命宫延迟
  return 300 + i * 80;      // 其他宫位延迟
}
```

### 禁用动画

```vue
<!-- 在组件上添加 prop -->
<ZiweiChart :chart="chart" :disable-animations="true" />
```

## 📝 注意事项

1. **性能考虑**：
   - 大量元素动画时注意性能
   - 使用 `will-change` 属性优化
   - 避免同时触发过多动画

2. **用户体验**：
   - 动画时长不宜过长（建议<1s）
   - 提供动画开关选项（未来功能）
   - 考虑用户的动画偏好设置

3. **浏览器兼容**：
   - 使用 `-webkit-` 前缀确保兼容性
   - 提供降级方案（无动画版本）
