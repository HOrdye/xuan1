# 天玄Web - 易经智慧决策系统

## 🎯 项目概述

天玄Web是一个专为90后、00后年轻人打造的玄学决策助手网页应用。系统通过现代化的网页技术，结合传统易经智慧与现代AI技术，为用户提供轻松访问、充满互动乐趣的玄学体验平台，帮助他们在决策过程中获得启发和指引。

**核心理念**: 告别刻板，拥抱"玄"妙乐趣，让每一次选择都有迹可循！

**系统定位**: 天玄Web 3.0 = 三维决策系统
- **易经（动态层）**：判断"何时做" - 基于时机的决策建议
- **紫微（静态层）**：分析"适合做什么" - 基于命盘特质的适配分析
- **塔罗（情感层）**：探索"内心真实想法" - 基于潜意识的情绪洞察

通过三大系统的深度融合，为用户提供多维度、全方位的决策辅助体验。

#### 前端核心
- **框架**: Vue 3.5.13 + TypeScript

#### 后端与数据
- **BaaS**: Supabase 2.51.0
- **HTTP客户端**: Axios 1.4.0
- **工具库**: UUID, Marked (Markdown解析)

#### 其他工具
- **图标**: FontAwesome 6.7.2
- **截图**: html2canvas 1.4.1
- **工具库**: @vueuse/core 10.11.1

├── components/           # 共享组件
│   ├── auth/            # 认证组件
│   ├── common/          # 通用组件
│   ├── hexagram/        # 卦象组件
│   └── profile/         # 用户资料组件
├── core/                # 核心服务
│   ├── services/        # 服务层（Supabase, Auth, LLM等）
│   └── types/           # 核心类型定义
├── store/               # Pinia状态管理
├── router/              # 路由配置
├── composables/         # 组合式函数
├── utils/               # 工具函数
└── views/               # 页面视图

### 核心原则

1. **价值多元化**: 会员权益覆盖所有六大功能模块，而非仅限单一功能
2. **渐进式体验**: 从免费到付费的转化必须自然，基于用户真实需求
3. **心理定价**: 价格策略符合90/00后用户心理预期和支付能力
4. **场景化升级**: 在用户最需要高级功能的时刻提供升级选项

**设计理念**: 会员系统不是"付费墙"，而是"价值交付系统"。会员权益的核心不是限制功能，而是提供与用户成长阶段匹配的价值体验。
