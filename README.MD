# 天玄Web - 易经智慧决策系统

## 🎯 项目概述

天玄Web是一个专为90后、00后年轻人打造的玄学决策助手网页应用。系统通过现代化的网页技术，结合传统易经智慧与现代AI技术，为用户提供轻松访问、充满互动乐趣的玄学体验平台，帮助他们在决策过程中获得启发和指引。

**核心理念**: 告别刻板，拥抱"玄"妙乐趣，让每一次选择都有迹可循！

## 🏗️ 系统架构

### 技术栈

#### 前端核心
- **框架**: Vue 3.5.13 + TypeScript
- **构建工具**: Vite
- **路由**: Vue Router 4.5.1
- **状态管理**: Pinia 2.1.3 + 持久化插件
- **UI库**: Naive UI 2.34.4
- **样式**: Tailwind CSS

#### 动画与3D
- **动画库**: Anime.js 3.2.1, GSAP 3.13.0
- **3D渲染**: Three.js 0.178.0
- **物理引擎**: Cannon-es 0.20.0
- **Lottie动画**: lottie-web 5.12.2

#### 后端与数据
- **BaaS**: Supabase 2.51.0
- **HTTP客户端**: Axios 1.4.0
- **工具库**: UUID, Marked (Markdown解析)

#### 其他工具
- **图标**: FontAwesome 6.7.2
- **截图**: html2canvas 1.4.1
- **工具库**: @vueuse/core 10.11.1

### 核心模块架构


## 🔧 开发指南

### 环境要求
- **Node.js**: 18+
- **npm**: 9+
- **Git**: 最新版本

### 安装步骤

```bash
# 1. 克隆项目
git clone [repository-url]
cd windsurf-xuan

# 2. 安装依赖
npm install

# 3. 配置环境变量
# 创建 .env 文件，配置以下变量：
# VITE_SUPABASE_URL=your_supabase_url
# VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
# VITE_DEEPSEEK_API_KEY=your_deepseek_api_key

# 4. 启动开发服务器
npm run dev

# 5. 构建生产版本
npm run build

# 6. 预览生产构建
npm run preview
```

### 开发规范

#### 代码规范
- **语言**: 使用TypeScript进行类型安全开发
- **框架**: 遵循Vue 3 Composition API最佳实践
- **样式**: 使用Tailwind CSS进行样式开发
- **注释**: 保持代码注释的完整性和准确性

#### 项目结构规范
- **功能模块**: 按功能划分到 `src/features/` 目录
- **共享组件**: 放在 `src/components/` 目录
- **工具函数**: 放在 `src/utils/` 或功能模块的 `utils/` 目录
- **类型定义**: 放在 `src/types/` 或功能模块的 `types/` 目录

#### Git工作流
- 使用 `dev-ui2` 分支进行开发
- 主分支保持稳定
- 提交信息清晰明确
