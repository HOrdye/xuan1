# 解读界面关键词句突出功能 - 使用说明

## 功能概述

已实现**方案一：高亮标签 + 引用框**，用于在解读界面突出显示关键词句，提升用户阅读体验。

## 实现内容

### 1. 格式化工具
- **文件位置**：`src/utils/contentFormatter.ts`
- **函数**：`formatContentScheme1()`
- **功能**：自动识别并标记以下内容：
  - 章节标题（【本卦分析】、【动爻推演】等）
  - 易经引用（带引号的句子）
  - 关键建议词汇（见好即收、见善则迁等）
  - 结论性语句（综合、建议、结论等开头的句子）
  - 重要时间（4-5个月等）

### 2. 样式定义
- **文件位置**：`src/views/HistoryDetail.vue` 的 `<style>` 部分
- **样式类**：
  - `.interpretation-section-title` - 章节标题样式
  - `.yijing-quote` - 易经引用样式
  - `.key-advice` - 关键建议样式
  - `.conclusion-highlight` - 结论高亮样式
  - `.time-badge` - 时间徽章样式

### 3. 集成位置
- **文件**：`src/views/HistoryDetail.vue`
- **函数**：`formatContent()` 已更新为使用方案一的格式化函数

## 视觉效果

### 章节标题
- 黄色渐变背景
- 左侧4px黄色边框
- 带📖图标
- 大号加粗字体

### 易经引用
- 紫色文字
- 斜体显示
- 浅紫色背景
- 左侧3px紫色边框

### 关键建议
- 黄色高亮背景
- 加粗字体
- 圆角边框

### 结论段落
- 绿色背景
- 左侧4px绿色边框
- 浅绿色文字
- 独立卡片样式

### 时间徽章
- 蓝色背景
- 圆角徽章样式
- 加粗字体

## 使用方法

功能已自动集成，无需额外配置。所有通过 `formatContent()` 函数处理的解读内容都会自动应用关键词句突出效果。

## 可扩展性

如需添加更多关键词或调整样式：

1. **添加关键词**：在 `contentFormatter.ts` 的 `keyPhrases` 数组中添加
2. **调整样式**：在 `HistoryDetail.vue` 的 `<style>` 部分修改对应CSS类
3. **切换方案**：如需使用其他方案，修改 `formatContent()` 函数中的调用

## 注意事项

- 格式化函数会按顺序处理内容，避免重复标记
- 支持中文引号（""）和英文引号（""）
- 关键词按长度从长到短排序，避免短词覆盖长词
