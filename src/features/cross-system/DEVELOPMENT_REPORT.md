## 🎯 核心特性

### 1. LLM智能综合分析

- **优先使用LLM**：如果配置了LLM API，优先使用LLM生成综合分析
- **智能提示词**：构建专业的综合分析提示词，包含三个系统的完整信息
- **JSON解析**：支持JSON格式响应解析，提取结构化数据
- **降级方案**：LLM不可用时，使用增强的多维度分析算法

### 2. 多维度分析

- **一致性分析**：评分0-100分，级别高/中/低
- **冲突性分析**：检测观点冲突，提供调和建议
- **互补性分析**：说明各系统的互补关系

### 3. 实时进度跟踪

- **各系统独立状态**：实时显示各系统的加载状态
- **进度回调**：通过回调函数实时更新UI状态
- **错误隔离**：某个系统失败不影响其他系统

### 4. 完善的错误处理

- **错误提示**：友好的错误信息展示
- **降级机制**：综合分析失败时自动降级
- **部分成功**：即使部分系统失败，仍显示成功的结果

## 📊 技术架构

### 服务层架构

```
AnalysisServiceManager（服务管理器）
├── performIndependentAnalysis（独立分析）
│   ├── YijingAnalysisService（易经分析）
│   ├── ZiweiAnalysisService（紫微分析）
│   └── TarotAnalysisService（塔罗分析）
└── performIntegratedAnalysis（综合分析）
    ├── 调用独立分析
    └── IntegratedAnalysisService（综合分析）
        ├── generateLLMInsight（LLM生成）
        └── generateEnhancedInsight（降级方案）
            ├── 一致性分析
            ├── 冲突性分析
            └── 互补性分析
```

### 数据流

```
用户输入问题
  ↓
选择系统和模式
  ↓
AnalysisServiceManager
  ↓
各系统并行分析（带进度回调）
  ↓
综合分析（LLM或降级算法）
  ↓
多维度分析结果
  ↓
UI展示
```

## 📝 使用说明

### 基本使用

1. 访问 `/triple-analysis` 路由
2. 输入问题
3. 选择要使用的系统（易经/紫微/塔罗）
4. 如果选择了2个或以上系统，可以选择是否启用"综合分析决策"
5. 点击"开始三维分析"
6. 查看结果：
   - 独立模式：只显示各系统的独立结果
   - 综合模式：显示各系统结果 + 多维度分析 + 综合洞察

### 综合分析功能

启用综合分析后，将显示：
- **一致性分析**：三个系统结果的一致性评分和分析
- **冲突性分析**：检测是否存在观点冲突
- **互补性分析**：说明各系统的互补关系
- **AI综合洞察**：基于三个系统的综合建议
- **优先行动清单**：按优先级排序的行动建议
