## 📋 测试清单

### ✅ 功能测试

#### 1. 基础交互测试
- [ ] **悬停显示提示框**
  - 鼠标悬停在星曜名称上，提示框应在200ms后显示
  - 提示框位置应跟随鼠标，但不超出屏幕边界
  - 提示框内容正确显示（术语名称、简介、分类）

- [ ] **点击显示详情弹窗**
  - 点击术语名称，应弹出详细解释弹窗
  - 弹窗中可以切换"简单解释"和"专业解释"
  - 弹窗内容正确显示

- [ ] **防抖功能**
  - 快速移动鼠标，提示框不应频繁闪烁
  - 悬停延迟约200ms，离开延迟约100ms

#### 2. 性能测试
- [ ] **懒加载**
  - 首次访问页面时，术语数据不应立即加载
  - 只有当悬停或点击术语时才加载数据
  - 加载时间应 < 100ms

- [ ] **位置更新性能**
  - 鼠标移动时，提示框位置更新流畅
  - 使用节流，每50ms最多更新一次
  - 无明显卡顿或延迟

#### 3. 样式测试
- [ ] **提示框样式**
  - 背景色、边框、阴影正确显示
  - 文字大小、颜色、行距正确
  - 圆角、内边距正确

- [ ] **动画效果**
  - 提示框淡入淡出动画流畅
  - 无闪烁或抖动

## 🧪 测试步骤

### 1. 准备测试环境
```bash
# 启动开发服务器
npm run dev

# 打开浏览器开发者工具
# - 打开 Console 标签页
# - 打开 Network 标签页
# - 打开 Performance 标签页（可选）
```

### 2. 功能测试步骤

#### 步骤1：测试悬停功能
1. 打开紫微斗数页面
2. 找到任意星曜名称（如"紫微"）
3. 将鼠标悬停在名称上
4. 观察提示框是否在200ms后显示
5. 移动鼠标，观察提示框位置是否跟随
6. 将鼠标移开，观察提示框是否在100ms后隐藏

#### 步骤2：测试点击功能
1. 点击任意星曜名称
2. 观察是否弹出详细解释弹窗
3. 切换"简单解释"和"专业解释"按钮
4. 观察内容是否正确切换
5. 关闭弹窗

#### 步骤3：测试性能
1. 打开浏览器开发者工具的 Network 标签页
2. 刷新页面
3. 检查是否加载了 `termExplanations.ts`（应该没有立即加载）
4. 悬停在一个术语上
5. 检查是否此时才加载术语数据
6. 检查加载时间是否 < 100ms

#### 步骤4：测试防抖和节流
1. 快速移动鼠标经过多个术语
2. 观察提示框是否频繁闪烁（应该不会）
3. 观察提示框位置更新是否流畅（应该流畅）
