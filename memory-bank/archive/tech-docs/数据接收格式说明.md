# 八宫六十四卦详细表 - 数据接收格式

## 📋 数据结构定义

为了便于接收和处理您提供的八宫六十四卦详细表，请按照以下格式提供数据：

### TypeScript 类型定义

```typescript
/**
 * 八宫六十四卦详细数据
 */
export interface HexagramPalaceData {
  /** 卦序号（1-64） */
  number: number;
  
  /** 中文卦名 */
  chineseName: string;
  
  /** 卦宫归属（八宫之一） */
  palace: '乾' | '兑' | '离' | '震' | '巽' | '坎' | '艮' | '坤';
  
  /** 五行属性 */
  element: '金' | '木' | '水' | '火' | '土';
  
  /** 世爻位置（0-5，对应初爻到上爻） */
  shiYao: number;
  
  /** 纳甲地支序列（6个地支，对应6个爻位） */
  naJiaSequence: [
    string,  // 初爻地支
    string,  // 二爻地支
    string,  // 三爻地支
    string,  // 四爻地支
    string,  // 五爻地支
    string   // 上爻地支
  ];
}

/**
 * 应爻位置计算规则
 * 根据世爻位置自动计算应爻位置
 */
export function calculateYingYao(shiYao: number): number {
  // 世应在六爻体系中的对应关系：
  // 世在初爻(0) → 应在四爻(3)
  // 世在二爻(1) → 应在五爻(4)
  // 世在三爻(2) → 应在六爻(5)
  // 世在四爻(3) → 应在初爻(0)
  // 世在五爻(4) → 应在二爻(1)
  // 世在六爻(5) → 应在三爻(2)
  const yingYaoMap: { [key: number]: number } = {
    0: 3, 1: 4, 2: 5,
    3: 0, 4: 1, 5: 2
  };
  return yingYaoMap[shiYao] ?? 0;
}
```

## 🔍 数据验证要求

为确保数据准确性，请确保：

1. **卦序号**：1-64，不重复
2. **卦名**：与 `hexagrams.json` 中的 `chineseName` 对应
3. **卦宫**：必须是八宫之一（乾、兑、离、震、巽、坎、艮、坤）
4. **五行**：必须是五行之一（金、木、水、火、土）
5. **世爻位置**：0-5之间的整数
6. **纳甲地支序列**：包含6个地支，必须是十二地支之一（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥）
