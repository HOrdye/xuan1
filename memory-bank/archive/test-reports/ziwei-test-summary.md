## 🔧 调试技巧

### 查看控制台
打开浏览器开发者工具（F12），查看Console输出

### 检查Store状态
```javascript
// 在浏览器控制台执行
import { useZiweiStore } from '@/features/ziwei/store/ziweiStore';
const store = useZiweiStore();
console.log(store.currentChart);
```

### 验证数据结构
```javascript
const chart = store.currentChart;
console.log('五行局:', chart.wuxingJu);
console.log('命宫:', chart.mingGong);
console.log('格局:', chart.patterns);
console.log('大限:', chart.daxian);
```
