### ❌ 发现的问题

#### 1. 命宫星曜显示错误 ⚠️ **已修复**
**问题描述**：
- 命宫显示为空，但基本信息显示命宫主星是"太阳、天梁"
- "太阳、天梁"显示在"夫妻宫"位置
- 宫位和星曜的对应关系错乱

**根本原因**：
- 在`assemblePalaces`方法中，宫位被重新排序（命宫调整到索引0）
- 但在返回`ZiweiChart`时，`mingGong`和`shenGong`仍使用原始索引
- 导致引用错误

**修复方案**：
```typescript
// 修复前
mingGong: palaces[mingGongIndex],  // 错误：使用原始索引
shenGong: palaces[shenGongIndex],   // 错误：使用原始索引

// 修复后
mingGong: palaces[0],  // 正确：重新排序后命宫在索引0
shenGong: palaces[(shenGongIndex - mingGongIndex + 12) % 12],  // 正确：计算新位置
```
