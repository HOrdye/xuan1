## 🔧 修改内容

### 1. `src/features/dilemma/views/DilemmaPage.vue`

**修改点**:
- ✅ 添加导入：`generateTraditionalAnalysisCoin` 和 `TraditionalAnalysis` 类型
- ✅ 在 `startAnalysis` 函数中，生成卦象后立即生成传统逻辑分析
- ✅ 修改 `getScenarioBasedAnalysis` 函数签名，接收 `traditionalAnalysis` 参数
- ✅ 将传统逻辑分析传递给 `LLMService.getScenarioBasedDilemmaInterpretation`
- ✅ 将传统逻辑分析保存到 `analysisResult.value.traditionalAnalysis`

**关键代码**:
```typescript
// 生成传统逻辑分析
const traditionalAnalysis = generateTraditionalAnalysisCoin(
  result.hexagram,
  result.changingLines,
  result.relatedHexagram
);

// 传递给AI解读
aiAnalysis = await getScenarioBasedAnalysis(
  result.hexagram, 
  scenario, 
  traditionalAnalysis
);
```

## ✅ 预期效果

修改完成后，两难抉择功能的AI解读应包含：

1. **动爻的具体含义**：
   - 不再显示"变爻含义解读中..."
