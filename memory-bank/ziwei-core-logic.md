## 一、命盘的"固定"与"变化"

### 本命盘（固定部分）

根据出生时间排出的命盘是**固定不变的**，包括：

- 十二宫位的位置
- 命宫所在位置
- 主星（紫微、天机、太阳等14颗主星）的分布
- 辅星、煞星的位置
- 四化（生年四化）

**这就像你的基因密码，终生不变。**

### 流年盘（变化部分）- 这是关键！

紫微斗数的精髓在于**时间推移带来的变化**：

#### 1. 流年（每年变化）

- 每一年都有对应的天干地支
- 每年会产生新的"四化"（化禄、化权、化科、化忌）
- 这些四化会飞入本命盘的不同宫位，影响当年运势
- 例如：2024年（甲辰年）和2025年（乙巳年）的四化完全不同

#### 2. 流月（每月变化）

- 每个月的运势起伏
- 更细致的时间分析

#### 3. 流日（每日变化）

- 每天的吉凶
- 适合做什么、不适合做什么

#### 4. 大运（每10年变化）

- 人生每10年为一个大运
- 大运会改变命宫的位置
- 每个大运关注的宫位和星曜不同
- 例如：0-9岁走第一个大运，10-19岁走第二个大运

### 类比理解

- **本命盘** = 你的性格、天赋、命运框架（硬件）
- **流年/大运** = 不同时期的际遇、机会、挑战（运行环境）

**所以用户需要反复使用的原因：**

- 每年查看流年运势
- 每个月查看流月运势
- 遇到重大决策时查看近期运势
- 每10年换大运时需要重新解读

## 二、空宫的含义

### 什么是空宫

命盘有12个宫位，但主星只有14颗（紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军），分布时会有些宫位**没有主星**，这就是"空宫"。

### 空宫的解读方式

#### 1. 借对宫的星

- 空宫不是"空白"，而是要看对面宫位的星曜
- 例如：命宫空，就看迁移宫（对宫）的星曜来论命

#### 2. 空宫的特性

- **可塑性强**：不受主星固定特质束缚，更灵活
- **受环境影响大**：容易受外界、他人影响
- **需要主动性**：不像有主星那样有明确特质，需要自己探索
- **看辅星煞星**：空宫的吉凶要看里面的辅星、煞星组合

#### 3. 不同宫位空宫的意义

**命宫空宫：**
- 个性较不强烈，适应能力强
- 人生方向需要自己摸索
- 借迁移宫的星来看性格

**夫妻宫空宫：**
- 婚姻缘分较平淡
- 配偶可能个性不明显
- 借官禄宫看配偶特质

**事业宫空宫：**
- 事业方向多样化
- 适合自由职业或多重身份
- 借夫妻宫看事业发展

**财帛宫空宫：**
- 财运起伏较大
- 赚钱方式不固定
- 借福德宫看财运状况

### 空宫不是坏事

传统上，空宫常被误解为"不好"，其实：

- 有主星 = 特质明显，但也受限
- 空宫 = 可能性多，但需努力

## 三、紫微斗数的完整逻辑框架

```
基础层（固定）
├─ 本命盘
│  ├─ 十二宫位
│  ├─ 命宫位置
│  ├─ 主星分布
│  ├─ 辅星、煞星
│  └─ 生年四化

时间层（变化）
├─ 大运（10年一变）
│  └─ 大运命宫、大运十二宫
├─ 流年（1年一变）
│  └─ 流年四化
├─ 流月（1月一变）
└─ 流日（1日一变）

分析层（组合解读）
├─ 星曜组合
├─ 四化飞星
├─ 宫位互涉
└─ 格局高低
```

## 四、如何在网站中呈现这些内容

### 1. 新手引导页

**标题：认识你的紫微命盘**

#### 什么是本命盘？

- 用通俗语言解释（类比"人生剧本"）
- 说明它代表天赋、性格、命运框架

#### 为什么每年都要看？

- 解释流年的概念
- 类比"同样的船，每年遇到不同的风浪"

#### 空宫是什么？

- 避免用户误解
- 强调"不是缺陷，是特色"

### 2. 命盘页面的信息层级

#### 一级信息（首次查看）：

- 显示本命盘
- 标注主星位置
- 简要说明命宫主星特质

#### 二级信息（引导深入）：

- "查看你的2025年运势"（引导到流年）
- "你现在走什么大运？"（引导到大运）
- "本月运势如何？"（引导到流月）

#### 三级信息（付费内容）：

- 详细的星曜组合解读
- 四化飞星影响分析
- 重要时间节点提醒

### 3. 专门的"空宫解读"页面

可以做一个独立页面：

- **标题：你的命盘中的空宫**
- 列出哪些宫位是空宫
- 每个空宫的对宫是什么星
- 这个空宫对你意味着什么
- 如何发挥空宫优势

### 4. 术语词典

建议做一个弹出式词典功能：

- 用户点击"空宫"、"四化"、"大运"等术语
- 弹出简洁解释
- 配合图示说明

### 5. 可视化时间轴

#### 大运时间轴：

```
0-9岁    10-19岁   20-29岁   30-39岁 ← 你现在在这里
[大运1]   [大运2]   [大运3]   [大运4]
```

#### 流年选择器：

```
◀ 2024年 | 2025年 | 2026年 ▶
当前流年运势：★★★★☆
```

## 五、内容撰写建议

### 用现代语言解释传统概念

#### 传统说法：

"命宫空宫，借对宫迁移宫之星论命"

#### 现代表达：

"你的命宫没有主星，这意味着你的个性不像有主星的人那么鲜明固定。你的性格更像一块海绵，容易受到环境和身边人的影响。想了解你的性格特质，要看对面'迁移宫'的星曜。这让你的可塑性强，但也要注意不要过度迎合他人而失去自我。"

### 避免过于玄学的表述

#### 不建议：

"流年化忌入命，大凶之兆"

#### 建议：

"今年要特别注意情绪管理和人际关系，可能会遇到一些挑战，但这也是成长的机会。建议多听取他人建议，谨慎做重大决定。"

## 六、产品功能对应

基于以上知识，产品功能可以这样设计：

| 内容类型 | 免费/付费 | 更新频率 |
|---------|----------|---------|
| 本命盘查看 | 免费 | 固定不变 |
| 命宫简要解读 | 免费 | 固定不变 |
| 空宫说明 | 免费 | 固定不变 |
| 当前大运分析 | 部分免费 | 10年一变 |
| 流年运势 | 付费 | 每年更新 |
| 流月运势 | 付费 | 每月更新 |
| 流日吉凶 | VIP | 每日更新 |
| 重大决策择日 | 付费 | 按需查询 |

这样用户就有**持续使用**的理由了！

## 八、关键设计原则

1. **降低理解门槛**：用现代语言和类比解释传统概念
2. **避免误解**：特别强调空宫不是缺陷，是特色
3. **引导深入**：通过信息层级设计引导用户探索
4. **持续使用**：通过流年/流月/流日功能创造持续使用理由
5. **商业化路径**：免费基础功能 + 付费深度解读
