### 测试3：Profile自动创建验证

#### 验证步骤：
在Supabase Dashboard的SQL Editor中执行：

```sql
-- 查看最新注册的用户和对应的profile
SELECT 
  u.id,
  u.email,
  u.created_at as user_created_at,
  p.username,
  p.preferences,
  p.created_at as profile_created_at
FROM auth.users u
LEFT JOIN public.profiles p ON u.id = p.id
ORDER BY u.created_at DESC
LIMIT 5;
```

#### 预期结果：
- ✅ 每个用户都应该有对应的profile记录
- ✅ profile的`created_at`应该与用户的`created_at`非常接近（自动创建）
- ✅ `preferences`应该包含默认值：`{"theme": "default", "language": "zh-CN", "notifications": true}`

### 测试7：历史记录保存测试（可选）

#### 步骤：
1. 登录用户
2. 进行一次占卜操作（例如：易经占卜、两难抉择等）
3. 检查历史记录是否保存到Supabase

#### 验证方法：
在Supabase Dashboard的SQL Editor中执行：

```sql
-- 查看用户的历史记录
SELECT 
  h.id,
  h.type,
  h.question,
  h.created_at,
  u.email
FROM public.divination_history h
JOIN auth.users u ON h.user_id = u.id
ORDER BY h.created_at DESC
LIMIT 10;
```

#### 预期结果：
- ✅ 历史记录成功保存到`divination_history`表
- ✅ 记录包含正确的`user_id`、`type`、`question`和`result`
