## 🎯 核心目标

### 总体定位
从"占卜工具"升级为"人生决策操作系统"

**天玄Web 3.0 = 三维决策系统**
- **易经（动态层）**：判断"何时做"
- **紫微（静态层）**：分析"适合做什么"
- **塔罗（情感层）**：探索"内心真实想法"

### 四大核心目标
1. **降低门槛** - 通过游戏化入口让年轻人3分钟上手紫微斗数
2. **深度融合** - 紫微与现有四大功能（易经、塔罗、两难、运势）深度整合
3. **独特价值** - 创造市面上没有的"三维决策"+"人生模拟"体验
4. **商业闭环** - 从免费体验到付费转化的完整路径

## 📝 开发任务拆分

### Phase 1: MVP核心功能（Week 1-2）

#### Task 1.1: 游戏化入口 - 人格测试（心理学优化）⭐⭐⭐⭐⭐
**吸引力**：极高 | **工作量**：中 | **优先级**：P0

**设计理念**：模糊化+积极框架，降低测试准确性风险

**子任务**：
- [ ] 1.1.1 创建人格测试组件（PersonalityTest.vue）
  - **Week 1 MVP**：3道选择题（简化版）
  - **Week 2-3迭代**：扩展到6道题（性格倾向2题 + 决策风格2题 + 价值观2题）
  - **完整版**：12道选择题（性格倾向4题 + 决策风格4题 + 价值观4题）
  - 每个选项对应1-2颗主星特质
  - 得分算法推测主星类型

- [ ] 1.1.2 测试结果展示（模糊化设计）
  - **原版**："你可能是【七杀型】人格"
  - **优化版**："你具有【开拓者】特质，与七杀、破军等星曜共鸣"
  - **优势**：即使不准，用户也能找到共鸣点
  - 引导跳转到排盘输入

- [ ] 1.1.3 对比展示（积极框架）
  - **原版**："测试结果 vs 实际结果"
  - **优化版**："你的自我认知 vs 星盘揭示"
  - **框架**：不是对错，而是不同视角的补充

- [ ] 1.1.4 引导文案优化
  - **原版**："验证猜测？输入生辰看看我们猜对了吗！"
  - **优化版**："解锁你的完整星盘，发现更多未知特质！"
  - **心理**：从验证变为探索，降低防御心理

- [ ] 1.1.5 测试数据存储
  - 保存测试结果到localStorage
  - 排盘后对比测试结果vs实际结果（但不强调对错）

**验收标准**：
- 用户3分钟内完成测试（Week 1 MVP）
- 测试结果引导到排盘输入
- 测试准确率>60%（简化版3道题即可）
- 用户不会因为"不准"而流失（模糊化设计）

#### Task 1.4: 三维解读面板（渐进式设计+信息过载防控）⭐⭐⭐⭐⭐
**吸引力**：极高 | **工作量**：低 | **优先级**：P0

**设计理念**：避免信息过载，渐进式展示，给用户控制权，动态调整信息密度

**子任务**：
- [ ] 1.4.1 问题分类算法
  - 关键词匹配 → 对应宫位
  - "工作/事业/职业" → 官禄宫
  - "感情/爱情/恋爱" → 夫妻宫
  - "赚钱/投资/理财" → 财帛宫
  - "健康/身体" → 疾厄宫
  - "学习/考试" → 官禄宫（文昌位）
  - "创业" → 官禄宫+财帛宫组合

- [ ] 1.4.2 第一层：快速诊断（Week 1 MVP极致简化版）
  - **Week 1 MVP优化**：单系统主导 + 另一系统简要提示（而非2系统完整展示）
  - **具体实施**：
    - 主要解读：基于问题类型选择最相关的1个系统进行深度解读
    - 其他视角：另一系统仅显示简要提示（1-2句话）+ "想深入了解？点击展开详细分析"
  - **示例**：
    ```
    用户问题: "我应该换工作吗？"
    
    【主要解读】紫微系统（官禄宫分析）
    - 你的官禄宫有XX星，适合XX类型工作
    - 当前流年显示XX时机较好
    
    【其他视角】易经系统（简要提示）
    - 易经角度：当前卦象显示宜静不宜动
    - 想深入了解？点击展开详细分析
    ```
  - **优势**：主次分明，避免认知负担
  - **Week 2-3迭代**：升级为2系统完整展示
  - UI：简洁展示，避免信息过载
  - **新增**：显示"当前信息密度"指示器（如1/3系统）

- [ ] 1.4.3 第二层：深度探索（用户主动触发）
  - 触发：用户点击"我想看更全面的分析"
  - 内容：展开第三个系统
  - 价值：给控制权给用户，避免信息过载
  - **新增**：更新"当前信息密度"指示器（3/3系统）

- [ ] 1.4.4 第三层：AI综合（付费用户或深度探索后）
  - 触发：付费用户或完成深度探索后
  - 内容：AI综合分析 + 置信度评分
  - 商业：成为付费钩子

- [ ] 1.4.5 规则引擎层（混合智能系统）
  - 功能：处理标准化解读
  - 覆盖：70%常见问题类型
  - 优势：稳定、准确、快速
  - 示例：官禄宫紫微→领导力相关模板

- [ ] 1.4.6 模板系统层（分阶段模板建设）
  - **调整**：分阶段建设模板库（而非一次性完成20个）
  - **Week 1**：5个核心场景模板
    - 场景：["换工作", "感情困惑", "财运问题", "健康关注", "学习考试"]
    - 要求：每个模板200-300字，确保专业准确
    - 方法：1名紫微专家 + 1名文案协作，与开发并行
  - **Week 2-3**：扩展到12个场景
    - 新增：["创业选择", "城市迁移", "人际关系", "家庭问题", "职业规划", "投资决策", "心理压力"]
  - **Week 4-6**：完善到20+场景
    - 新增：["特定年龄段问题", "特殊星曜组合", "复杂格局解读"]
  - **质量保障**：
    - 专家审核：每个模板必须经过紫微斗数专家审核
    - 用户测试：上线后收集用户评分，低分模板立即优化
    - 迭代机制：建立模板版本管理和持续优化流程
  - **新增**：为每个模板添加"传统依据"和"现代解读"说明
  - 示例：夫妻宫空宫借对宫的详细解读模板

- [ ] 1.4.7 LLM增强层（个性化润色+质量分级）
  - 功能：个性化润色+特殊情况处理
  - 输入：规则引擎输出 + 用户具体情境
  - 优势：结合稳定性与灵活性
  - 降级：LLM失败时回退到模板
  - **新增**：AI质量分级系统（见下方详细说明）

- [ ] 1.4.8 跨系统分析引擎
  - 易经层：判断时机（当前卦象、宜动/宜静、最佳行动时间）
  - 紫微层：分析适配度（相关宫位主星、星曜特质匹配、成功概率）
  - 塔罗层：探索潜意识（抽到的牌、潜意识信号、情感顾虑）

- [ ] 1.4.9 置信度算法+质量分级
  - 判断三者一致性
  - 计算置信度评分（0-100）
  - **新增**：AI质量分级系统（见下方详细说明）

- [ ] 1.4.10 **新增**：动态信息密度控制
  - 根据用户行为动态调整信息密度
  - 指标：用户平均阅读时间、信息跳过率
  - 算法：if (timeOnPage < 15s) → "light"模式；else if (timeOnPage > 30s) → "full"模式；else → "medium"模式
  - UI：允许用户在设置中选择"简洁模式"或"详细模式"

- [ ] 1.4.11 **新增**：认知舒适区引导
  - 在三维解读面板增加"当前信息密度"指示器（如2/3、3/3、全）
  - 提示用户当前处于哪个认知层级
  - 引导用户逐步深入探索

**AI质量分级系统**（新增）：
| 置信度 | 算法 | 显示方式 | 付费门槛 |
|--------|------|---------|---------|
| 90%+ | 规则引擎+模板 | 显示"高置信度" | 免费 |
| 70-89% | 规则引擎+模板+LLM | 显示"中置信度" | 免费 |
| 50-69% | 仅LLM | 显示"低置信度" | 付费 |
| <50% | 降级到模板 | 显示"建议参考" | 免费 |

**验收标准**：
- 用户输入问题后，3秒内看到快速诊断
- 信息密度适中，阅读完成率>70%
- 规则引擎覆盖70%常见问题
- LLM失败时自动降级到模板
- **新增**：认知负荷指标监控（用户平均阅读时间、信息跳过率）
- **新增**：AI质量健康度指标（置信度分布、用户评分）

**技术要点**：
- 先用固定模板+规则引擎，绕过AI不确定性
- 设计为可插拔架构，方便替换AI/规则/模板
- 重点打磨"一致性分析"算法
- 建立质量监控机制（用户评分+人工审核样本）
- **新增**：建立AI质量监控看板（实时监控准确率、用户评分、置信度分布）
- **新增**：质量反馈闭环（用户"不太准确"反馈自动进入优化队列）

**AI质量运营体系**（新增）：
- **实时监控**：
  - 看板指标：每小时置信度分布、用户评分趋势、LLM调用失败率、降级到模板比例
  - 报警机制：置信度<50%的比例超过20%时立即报警
- **人工审核**：
  - 抽样规则：每日随机抽取5%的AI解读进行人工审核
  - 审核标准：专业性(40%) + 实用性(30%) + 个性化(30%)
  - 整改流程：低分解读→分析原因→优化模板→重新训练
- **用户反馈闭环**：
  - 收集机制：每个解读后都有"这个解读对你有帮助吗？"评分
  - 处理流程：1-2星评价自动进入优化队列，48小时内人工处理
  - 奖励机制：提供高质量反馈的用户给予积分奖励

- 先固定模板后AI：先用固定模板测试，再引入AI增强

```typescript
// 解读引擎可插拔架构
interface InterpretationEngine {
  // 规则引擎层：处理70%标准化解读

  templateSystem: TemplateSystem;
  
  // LLM增强层：个性化润色+特殊情况处理
  llmEnhancer: LLMEnhancer;
  
  // 降级策略：LLM失败时回退到模板
  fallbackStrategy: FallbackStrategy;
}
```

- ✅ 给用户控制权，主动选择是否查看完整分析
- ✅ 监控阅读完成率，目标>70%
- ✅ **新增**：动态信息密度控制（根据用户行为自动调整）
- ✅ **新增**：认知舒适区引导（显示当前信息密度指示器）

- ✅ **新增**：建立"信息过载指数"（阅读时间/信息量）

- ✅ 建立质量监控机制（用户评分+人工审核样本）
- ✅ 低分解读进入优化队列
- ✅ **新增**：AI质量分级系统（90%+高置信度免费，50-69%低置信度付费，<50%降级到模板）
- ✅ **新增**：建立AI质量监控看板（实时监控准确率、用户评分、置信度分布）
- ✅ **新增**：质量反馈闭环（用户"不太准确"反馈自动进入质量优化队列）
